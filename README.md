# Краудфандинговое веб-приложение «вЕзи»

Полнофункциональный клиентский проект краудфандинговой платформы **«вЕзи»** с открытой сметой, двойной шкалой прогресса, ролевыми личными кабинетами, светлой и тёмной темами оформления и базой данных `db.json`.

## Структура проекта

```text
vezi-crowdfunding/
├── index.html          # Главная страница (каталог проектов, поиск, фильтрация, вклад)
├── login.html          # Страница входа (валидация, защита от повторного входа)
├── register.html       # Страница регистрации новых пользователей в базу
├── sponsor.html        # Личный кабинет спонсора (вклады, доставка вознаграждений)
├── initiator.html      # Личный кабинет автора и интерактивный калькулятор сметы
├── moderator.html      # Личный кабинет модератора (проверка сметы, смена статусов)
├── admin.html          # Личный кабинет администратора (аналитика, роли, транзакции)
├── db.json             # База данных со всеми 7 таблицами и тестовыми записями
├── css/
│   └── style.css       # Стили интерфейса, светлая и тёмная темы, мобильная адаптивность
└── js/
    ├── db.js           # Загрузка и синхронизация db.json с localStorage, экспорт JSON
    ├── auth.js         # Авторизация, регистрация, контроль сессии и переключение тем
    ├── calculator.js   # Математический калькулятор сметы и управление дорожной картой
    └── app.js          # Поиск, фильтрация, оформление вкладов, модерация и админка
```

## Как запустить

1. Откройте `index.html` в любом браузере или запустите локальный сервер:
   ```bash
   python3 -m http.server 3000
   ```
2. Для подключения `db.json` как REST API через `json-server`:
   ```bash
   npx json-server --watch db.json --port 3001
   ```
